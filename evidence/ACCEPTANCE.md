## 5174 主动隔离复测

v0.1.0 的运行源码与发布标签一致。Mac mini 用 macOS 进程级网络限制阻断隔离副本的服务、执行器及浏览器到 TCP 5174 的连接。试验前后，从限制范围外访问 5174 健康接口正常，从限制范围内访问均失败。5374 隔离入口完成真实首问、同一任务刷新续接、针对第二篇论文的追问和 55 个图层分块读取。首问调用独立发现服务，追问新增发现调用为零。[实测证据](prototype-isolation/verification.json)

## 实测外部依赖

新进程沿用原型当前的模型与工具配置。原型 LaunchAgent 环境中已有 DeepSeek Key 及 Search、Fetch 开关。执行器沿用本机已登录会话。海纳 SDK 使用原有凭据来源，断言使用现有只读连接与原有查询入口。未复制凭据到发布目录。

DeepSeek Search 和 Fetch 均有真实成功返回。个别来源链接的 Fetch 返回 HTTP 404，部分 PDF 受远端或范围限制。各条失败独立记录，仍保留其他结果。日志内时间戳以本机 UTC 记录。

**机构登录仍待接入。** 现有原型工作入口提供 Host／Origin 校验，检查到的部署变量和代码没有独立 SSO 登录入口、issuer 或可验证身份集成配置。上游账号访问已经实测，网页入口当前仅在本机监听。复核了原型工作区、安装副本的环境变量名称、LaunchAgent 和部署说明。部署说明只记录本机访问、SSH 隧道、局域网 Host 校验和执行器登录。下一步需要现有网页登录入口、网关接入配置或其引用，以及项目权限映射的现有来源。联调时使用不同项目的现有测试身份，验证各自可打开本项目任务、事件和引用，并验证跨项目读取和取消请求被拒绝。

本次性能证据来自 Mac mini 本机 Chrome。没有新的局域网 Safari 客户端数据，交接包原有 Safari 结果条件不同，不纳入本次比较。

## ECS 交接

使用同一源码版本及锁文件。Mac mini 本机实测为 arm64。当前机器未发现可用 Linux 虚拟机或容器运行时，因此没有本机 Linux 执行记录。目标 Linux arm64 或 x64 安装 Node.js 26.0.0 与原锁文件依赖，按目标浏览器运行验收。原型继承的 `sharp`、`esbuild` 与浏览器二进制按目标平台安装。部署不复制 Mac 的 `node_modules` 或图层索引数据库文件。

ECS 注入现有登录和凭据引用、端点、网络、端口和写位置。配置 PostgreSQL 连接串和 PostGIS 扩展，以及 S3 兼容桶。云上须复跑图层范围和时段查询、对象写读、备份还原、无桌面执行器认证与外部连通性。线上入口及云端设备规模根据真实混合负载确定，并单独确认授权数据范围、切换窗口和回退。
